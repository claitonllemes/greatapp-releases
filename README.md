# GreatPages — releases

Binários e `latest.json` do app desktop [GreatPages](https://www.greatpages.com.br) para macOS (Apple Silicon). Este repositório só publica releases; o código não fica aqui. O app instalado consulta a release mais recente para se atualizar sozinho.

Para instalar, baixe o `.dmg` da [última release](https://github.com/claitonllemes/greatapp-releases/releases/latest).
